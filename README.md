# My Personal Website

> A clean and elegant personal website / blog

## Tech Stack

- HTML5 / CSS3 / JavaScript / Vue
- Responsive design, mobile-friendly

## Getting Started

```bash
# Clone the repo
git clone https://github.com/HGfds29/my-web.git

# Navigate to the folder
cd my-web

# Open in browser (or use Live Server)
open index.html
```
After deployment, your site will be available at:  
`https://HGfds29.github.io/my-web`

## Customization

1. Update personal info in all HTML files in the root directory
2. Replace images in `assets/` folder
3. Modify styles in `css/...`
